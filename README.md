# Blue Changes

Play-along de jazz para practicar con el móvil: cifrado americano, banda (piano, bajo y batería), cambios de 4, tema completo y transposición.

Web: https://zumodepato.github.io/Blue-Changes/

## Créditos de sonidos
- Piano: Salamander Grand Piano (Alexander Holm, CC BY 3.0), vía Tone.js/audio.
- Rhodes, vibráfono, contrabajo: MusyngKite; órgano, bajo eléctrico y sintetizado: FluidR3 GM (vía gleitz/midi-js-soundfonts).
- Batería: kit «Blonde Bop» de AVL Drumkits, creado por Glen MacArthur (http://www.bandshed.net/avldrumkits/), licencia CC-BY-SA 3.0; extraído de x42/avldrums.lv2. Escobilla de Tone.js/audio (Berklee).
- Catálogo de temas: listas públicas de la comunidad de iReal Pro (vía infojunkie/ireal-musicxml), se cargan al buscar.
